## 🛠️ Pre-Meetup Setup Requirements

To make the most of our first session, please complete these setup tasks:

### 1. Database Installation
Install PostgreSQL on your system:
- **macOS**: `brew install postgresql@15`
- **Windows**: Download from [postgresql.org](https://www.postgresql.org/download/windows/)
- **Linux**: `sudo apt install postgresql postgresql-contrib`

**Detailed instructions:** See `course/tools/postgresql/README.md` in the repository

### 2. Mermaid Account Setup
Create a free account at [mermaid.live](https://mermaid.live/) for diagram creation. We'll use this for visual domain modeling throughout the course.

### 3. VS Code Setup (Recommended)
If you don't already have VS Code installed:
1. Download from [code.visualstudio.com](https://code.visualstudio.com/)
2. Install the recommended extensions listed in `course/tools/vscode/README.md`

### 4. Review Course Overview
Please read the main `README.md` file in the repository to understand the course structure and philosophy.
